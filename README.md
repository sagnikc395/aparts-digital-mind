# The Alignment Tax of Introspection

Apart Digital Minds Research Sprint — Track 3: Introspection and Self-Report Reliability.

Ablating the refusal direction is reported to unlock introspective self-report. This
project treats that ablation as a **continuous dial** rather than a binary switch and
measures, on one dose-response axis, what the unlock costs:

| family | question | measures |
|---|---|---|
| A · introspection | what is gained? | detection, identification, joint rate, forced choice, `d'` |
| B · safety | what is lost? | refusal rate and safety score on JailbreakBench |
| C · capability | what else is lost? | CE loss, MMLU, TruthfulQA MC1, GSM8K |

Plus the question prior work leaves open: a **norm-matched random-direction control**
(condition C3) that separates *"the model detects this concept"* from *"the model
detects that something happened"*. The ratio `d'_random / d'_clean` is reported as the
**specificity index**.

Full design: [`EXPERIMENT_PLAN.md`](EXPERIMENT_PLAN.md). Write-up: [`paper/`](paper).

## Layout

```
src/alignment_tax/     core library — everything non-trivial lives here
  config.py            RunConfig: model, direction, injection, eval knobs
  model.py             residual-stream hooks: partial ablation + concept injection
  directions.py        refusal direction: diff-in-means + held-out selection
  concepts.py          concept vectors and the alpha normalisation
  prompts.py           structured / skeptical / prefill / forced-choice protocols
  introspection.py     the C1-C4 sweep and the go/no-go pilot
  safety.py            family B
  capability.py        family C
  stats.py             concept-level bootstrap, d', specificity index, Holm
  analysis.py          joins the families; computes the exchange rate
  figures.py           the four figures
  pipeline.py          resumable stages shared by the CLI and the notebooks
  cli.py               python -m alignment_tax.cli <stage>
notebooks/             single Colab runner (generated by scripts/build_notebooks.py)
data/                  concept bank, baseline corpus, offline fallback splits
results/<model>/       all run artifacts (JSONL + JSON), resumable by key
```

## Running it in Colab

`notebooks/alignment_tax_full_run.ipynb` is the whole experiment in one notebook,
a thin wrapper around `pipeline.py`. It clones this repo, installs deps, and mounts
Drive so results survive a session kill.

Before running, add two **Colab secrets** (key icon in the left sidebar) with
*Notebook access* on:

| Secret | Scope | Needed for |
| --- | --- | --- |
| `GITHUB_TOKEN` | `repo:read` | cloning while this repo is private |
| `HF_TOKEN` | read | downloading gated Hugging Face models |

Cell 0 reads each secret, falls back to the environment variable of the same name,
and only then prompts interactively; a blank answer skips it. Neither token is
written to disk. Run the notebook top to bottom:

0. **Environment** — clone, deps, results directory, bundled data files, config.
1. **Refusal direction** — checkpointed to `refusal_direction.pt`.
2. **Concept bank** — checkpointed to `concept_bank.pt`.
3. **Pilot** — the **go/no-go gate**. If forced-choice identification is at chance
   at both `λ=0` and `λ=1`, stop and switch models rather than spending the budget.
   Otherwise it locks the injection layer and `alpha`.
4. **Main sweep** — C1–C4 across `λ ∈ {0, .25, .5, .75, 1}`, plus the
   skeptical-prompt robustness check at the endpoints.
5. **Safety and capability** — families B and C.
6. **Analysis and figures** — bootstrap, exchange rate, the four figures, judge kappa.
7. **Export** — mirrors the run into `results/<model>/` (checkpoints, JSONL logs,
   analysis JSON, `figures/`), writes `MANIFEST.json` with per-file sha256, zips
   the run, then commits and pushes it back to the repo. The `GITHUB_TOKEN` Colab
   secret needs write access (`contents:write` on a fine-grained PAT) for that push.

Every sweep is **resumable**: records are keyed by `(λ, condition, concept, trial,
variant)` and appended to JSONL with an fsync, so re-running a cell after a
disconnect picks up exactly where it stopped.

## Running it from the CLI

```bash
pip install -e .
python -m alignment_tax.build_data                      # concept bank + fallbacks
python -m alignment_tax.cli all --smoke --device cpu    # tiny end-to-end check
python -m alignment_tax.cli pilot   --model Qwen/Qwen3-4B-Instruct-2507
python -m alignment_tax.cli sweep   --lambdas 0,0.25,0.5,0.75,1.0 --layer 29 --alpha 4
python -m alignment_tax.cli safety
python -m alignment_tax.cli capability
python -m alignment_tax.cli analyse && python -m alignment_tax.cli figures
```

`--smoke` swaps in `Qwen3-0.6B` with miniature splits so the whole pipeline can be
exercised on a laptop in minutes. Those numbers are a plumbing check, not a result.

## Tests and the write-up

```bash
python tests/test_analysis_stack.py      # model-free: parsing, stats, resumability, figures
python scripts/fill_paper.py results/<model>   # numbers -> paper/paper_filled.md
```

The test suite includes two synthetic sweeps — one with a genuine introspective channel
and one with sensitivity but no specificity — and checks that the analysis tells them
apart. Worth running before committing a long sweep to a GPU.

`paper/paper.md` is the prose with `{{placeholders}}`; `fill_paper.py` substitutes measured
values and leaves `[[MISSING: key]]` wherever a number does not exist yet, so an unfinished
results section is visibly unfinished. Figures are regenerated from `analysis_*.json` by
`python -m alignment_tax.cli figures` and are not checked in.

## Notes on the setup

- **bf16 only.** No FP8 or 4-bit for the primary model: block-quantisation noise would
  land on exactly the residual-stream path we inject into and read from.
- **Hooks, not weight surgery.** Mathematically equivalent, but hooks let `λ` sweep
  without a model reload, which is what makes the dose-response curve affordable.
- **Injection strength is normalised** to a multiple of the mean residual-stream norm
  at the injection layer, so `alpha` is comparable across layers and model families.
- **Bootstrap over concepts, not trials.** Concepts are the unit of generalisation.
- **No harmful completions leave the machine.** Safety generations stay in the local
  JSONL; only aggregate scores are exported.
